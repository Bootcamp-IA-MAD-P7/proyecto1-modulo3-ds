# F5 RiskAI

Prototipo de Machine Learning para estimar el riesgo de ictus a partir de datos de pacientes.

## Objetivo

Desarrollar un sistema que permita predecir la probabilidad de sufrir un ictus basándose en características clínicas y demográficas de los pacientes.

## Tecnologías

- **Python** — Lenguaje principal del proyecto
- **Scikit-learn** — Modelos de Machine Learning
- **FastAPI** — Backend y API REST
- **Vue.js** — Frontend
- **Git/GitHub** — Control de versiones

## Entorno de desarrollo

### Requisitos

- Python >= 3.10

### Configuración

```bash
# Crear entorno virtual
python -m venv .venv

# Activar entorno (Windows)
.venv\Scripts\activate

# Activar entorno (macOS/Linux)
source .venv/bin/activate

# Instalar dependencias
pip install -r requirements.txt
```
